# 서울이 선다 사용 가이드

발표 화면의 그림을 폰 카메라로 비추면 그림 위에 서울 25개 자치구가 3D로 서고, 발표자가 고른 구가 솟아오르며 법정동별 실거래 막대가 자랍니다. 발표자의 선택은 모든 관객 폰에 1초 안에 같이 바뀝니다.

| 역할 | 기기 | 주소 |
|---|---|---|
| 발표자 | 노트북 + 프로젝터(또는 큰 모니터) | https://d2zgenhitcakex.cloudfront.net/#/host |
| 관객 | 폰 (iOS Safari, Android Chrome) | https://d2zgenhitcakex.cloudfront.net (화면의 QR로 열림) |
| 카메라 없이 보기 | 아무 기기 | https://d2zgenhitcakex.cloudfront.net/#/3d |
| 무대(손짓) | 웹캠 달린 발표자 노트북 + 프로젝터 | https://d2zgenhitcakex.cloudfront.net/#/stage (발표자 화면의 "무대 열기") |

## 1. 전체 진행 순서

```
발표자                                    관객
──────────────────────────────            ──────────────────────────────
① 노트북에서 #/host 열기
② "슬라이드 모드" (S 키)
   → 화면에 그림 + QR + 제목만 남음
                                           ③ 폰 카메라로 QR 찍기 → 페이지 열림
                                           ④ "카메라 켜기" → 권한 허용
                                           ⑤ 발표 화면의 그림을 폰 화면에 담기
                                              → 그림 위에 서울 등장
⑥ Esc 로 슬라이드 모드 끝내기
⑦ 월 · 막대 기준 · 자치구 선택
   → 모든 폰이 1초 안에 따라옴             ⑧ 아래 요약에서 숫자 읽기
                                              흔들리면 "화면 고정"
                                           ⑨ 직접 다른 구를 보고 싶으면 아래 선택
                                              → "직접 보는 중", "라이브로 돌아가기"로 복귀
⑩ "전체 보기"로 마무리
```

발표 중에는 ②의 슬라이드 모드와 ⑦의 조작 화면을 S / Esc 로 오가면 됩니다. 조작 화면에서도 그림과 QR은 왼쪽에 그대로 보이므로, 프로젝터에 조작 화면을 띄운 채 진행해도 관객은 그림을 비출 수 있습니다.

손짓으로 3D 서울을 움직이는 무대 장면은 ⑦의 조작 화면에서 "무대 열기"로 들어갑니다(7절). 그동안 AR로 보던 폰에는 "무대 진행 중 · 3D로 따라가기" 배너가 뜹니다.

## 2. 발표자 화면 (노트북)

`#/host` 를 열면 두 열로 나뉩니다.

**왼쪽 (관객에게 보여 줄 화면)**
- 제목 "서울이 선다"
- AR 인식용 그림. 관객이 폰 카메라로 비추는 대상입니다.
- QR 코드. 지금 열려 있는 주소로 자동 생성되므로 따로 만들 필요가 없습니다. 안내 문구 "폰 카메라로 QR을 찍고, 열린 화면을 왼쪽 그림에 비춰 보세요"가 함께 뜹니다.

**오른쪽 (발표자 조정)**
- 연결 상태. "연결됨: 바꾸면 관객 폰에 바로 반영됩니다"가 보여야 정상입니다. "연결 중"이면 몇 초 기다리고, "연결 안 됨"이면 새로고침합니다.
- 월. 지금 들어 있는 데이터는 2026년 11월 한 달입니다.
- 막대 기준. "㎡당 가격" 또는 "거래 건수". 구 아래 숫자의 뜻이 함께 바뀝니다.
- 자치구. 25개 구 버튼. 누르면 그 구가 솟아오르고 법정동 막대가 자랍니다. "전체 보기"를 누르면 25개 구를 색으로만 비교하는 전체 화면으로 돌아갑니다.
- 슬라이드 모드 버튼. S 키와 같습니다. 전체 화면으로 들어가 그림, QR, 제목만 남깁니다. Esc 또는 "슬라이드 모드 끝내기"로 나옵니다.
- "무대 열기". 손짓으로 3D 서울을 움직이는 무대 화면(`#/stage`)으로 이 창에서 넘어갑니다. 사용법은 7절.
- "처음으로". 랜딩으로 돌아갑니다.

**월 가져오기**
- 오른쪽 아래 "월 가져오기"에서 달을 고르고(또는 `202610`처럼 직접 입력) "가져오기"를 누르면, AWS 안의 수집 작업이 서울 열린데이터광장에서 그 달의 25개 구 매매 실거래를 새로 모읍니다. 2006년 1월부터 이번 달까지 고를 수 있습니다.
- 처음 누를 때 발표자 암호를 묻습니다. 한 번 맞히면 이 탭을 닫을 때까지 다시 묻지 않습니다. "발표자 암호가 맞지 않습니다"가 뜨면 저장된 암호가 지워지고 다시 묻습니다.
- 진행 중에는 "2026년 10월 수집 중 12/25 · 강서구"처럼 몇 번째 구까지 끝났는지 보이고, 그동안 버튼은 눌리지 않습니다. 몇 분 걸립니다.
- 끝나면 "2026년 10월 데이터가 준비됐습니다" 알림이 뜨고 월 버튼에 새 달이 생깁니다. 그 달을 누르면 관객 폰도 새 달 자료를 다시 읽어 그대로 따라옵니다.
- "다른 달을 가져오는 중입니다"가 뜨면 앞선 작업이 끝난 뒤 다시 누릅니다.
- 수집이 끝나면 그 달의 AI 해설이 이어지는 작업으로 자동 생성되어, 보통 1분 안에 화면에 나타납니다.
- 암호를 10번 틀리면 그 접속 주소(공인 IP)가 10분 동안 막힙니다. 행사장 Wi-Fi는 관객과 같은 공인 IP를 쓰는 경우가 많으니, 발표자는 폰 핫스폿으로 접속하거나 암호를 한 번에 정확히 입력합니다.

**시간 여행**
- 월이 두 달 이상 들어 있으면 "시간 여행" 구역이 나타납니다. "재생"을 누르면 지금 달에서 다음 달로 차례로 넘어가고(마지막 달이었다면 첫 달부터), 마지막 달에서 멈춥니다. 반복하지 않습니다.
- 간격은 2초·4초·8초 중에서 고릅니다(기본 4초). 구와 막대 기준은 그대로 두고 월만 바뀌며, 관객 폰도 같은 순서로 따라옵니다. 같은 구를 보고 있으면 막대가 다시 자라지 않고 지금 높이에서 새 높이로 바뀝니다.
- 진행 줄 "2026년 9월 → 10월 → 11월"에서 굵게 표시된 달이 지금 달입니다.
- 재생 중에 월, 구, 막대 기준을 직접 누르거나 월 가져오기·해설 생성을 시작하면 재생이 멈춥니다. "일시정지"로도 멈출 수 있습니다.

**AI 해설**
- 구(또는 서울 전체)를 고르면 관객 폰의 요약 패널과 큰 화면에 그 달의 "AI 해설" 한 줄이 나옵니다. Amazon Bedrock의 Claude 모델이 집계 수치만 보고 자동으로 쓴 문장입니다. 사실을 짧게 요약할 뿐 투자 판단이나 전망을 담지 않으며, 참고용입니다. 화면에도 "Bedrock · 모델명 · 자동 생성, 참고용"이 함께 표시됩니다.
- 새로 가져온 달은 해설이 자동으로 만들어집니다. 이미 있던 달처럼 해설이 없는 달은 "월 가져오기" 구역의 "해설 생성"을 누릅니다(지금 고른 달에 해설이 없을 때만 눌립니다). 같은 발표자 암호를 씁니다. 끝나면 "해설이 준비됐습니다" 알림이 뜨고, 관객 폰에는 1분 안에 나타납니다.
- 해설이 없거나 그 구의 문장이 없으면 해설 줄은 아예 보이지 않습니다.

**큰 화면 모드**
- "큰 화면 열기"를 누르면 새 창에 큰 화면용 3D(`#/3d?stage=1`)가 열립니다. 이 창을 프로젝터 쪽 화면에 두고 전체 화면으로 키웁니다.
- 큰 화면은 언제나 발표자 선택을 따라가고 직접 조작은 되지 않습니다. 왼쪽 위에 구 이름과 월, 큰 숫자 세 개(㎡당 중앙값, 거래, 최고가)와 AI 해설이, 오른쪽 아래에 관객용 QR과 "폰으로 QR을 찍어 그림을 비춰 보세요" 안내가 나옵니다. 도시는 천천히 돌고(움직임 줄이기 설정이면 멈춤), 마우스를 잠시 움직이지 않으면 커서가 사라집니다.
- 무대(7절)를 진행하면 큰 화면은 펼치기·들어올리기·투표 결과에 더해 무대에서 돌린 각도와 확대도 따라옵니다.

**동작 원리**
- 월, 기준, 구를 바꿀 때마다 관객 폰으로 상태가 전송됩니다. 10초마다 같은 상태를 다시 보내므로 늦게 들어온 관객도 자동으로 따라옵니다.
- 전송이 실패하면 "관객 화면에 보내지 못했습니다. 연결 상태를 확인해 주세요."라는 알림이 뜹니다.

**발표 팁**
- 그림이 화면에서 클수록 멀리서도 인식됩니다. 슬라이드 모드에서는 그림이 가장 크게 나옵니다. 프로젝터라면 그림 한 변이 40cm 이상이면 2~3m 거리에서도 잡힙니다.
- 화면 밝기를 최대로, 조명 반사가 그림 위에 생기지 않게 합니다.
- 노트북 시계가 자동 설정(인터넷 시간)이어야 합니다. 폰보다 30초 이상 앞서 있으면 메시지가 위조로 간주되어 무시됩니다.
- 리허설 때 폰 한 대로 ③~⑨를 한 번 끝까지 해 봅니다.

## 3. 관객 화면 (폰)

**열기**
1. 발표 화면의 QR을 폰 카메라로 찍습니다. 설치 없이 브라우저로 열립니다.
2. 랜딩에서 "카메라로 보기"를 누릅니다. 카메라를 쓸 수 없는 기기면 "3D로 보기"로 넘어갑니다.
3. "카메라 켜기"를 누르고 브라우저의 카메라 권한을 허용합니다. 카메라 영상은 폰 밖으로 전송되지 않습니다.
4. "슬라이드의 그림을 비춰 주세요"가 뜨면 발표 화면의 그림이 폰 화면에 다 들어오게 폰을 듭니다. 거리는 보통 0.5~2m, 그림이 폰 화면의 절반 이상을 차지하면 가장 잘 잡힙니다.
5. 인식되면 그림 위에 서울이 섭니다. 발표자가 고른 구가 솟아 있고 법정동 막대가 자랍니다.

**읽기 (아래 요약 패널)**
- 맨 위: 지금 보는 지역(서울 전체 또는 구 이름)과 월, 그리고 상태 표시. "라이브: 발표자 화면을 따라가는 중"이 기본입니다.
- 숫자: ㎡당 중앙값(만원), 거래 건수, 최고가. 구를 보고 있으면 법정동 상위 5개 목록이 함께 나옵니다. 3D 라벨이 흔들려도 숫자는 여기서 읽습니다.
- "AI 해설": 숫자 아래 한 줄 요약입니다. AI(Amazon Bedrock)가 집계 수치로 자동 생성한 참고용 문장이며, 해설이 없는 달에는 나오지 않습니다.
- "가격 / 건수" 토글: 막대 기준을 폰에서만 바꿔 볼 수 있습니다.
- "막대와 색의 기준": 색 범례와 정의가 펼쳐집니다.

**흔들릴 때: 화면 고정**
- "화면 고정"을 누르면 카메라 영상과 추적이 멈추고 마지막 장면이 그대로 남아 숫자를 차분히 읽을 수 있습니다. 상태가 "고정됨"으로 바뀌고 버튼은 "다시 추적"이 됩니다.
- 발표자가 구를 바꾸면 고정 중에도 숫자와 막대는 새 값으로 갱신됩니다. 장면 위치만 고정됩니다.
- "다시 추적"을 누르면 카메라가 다시 켜집니다.

**직접 둘러보기**
- 요약 패널의 자치구, 월 선택을 직접 바꾸면 "직접 보는 중"으로 바뀌고 발표자 선택을 따라가지 않습니다.
- "라이브로 돌아가기"를 누르면 다시 발표자 화면을 따라갑니다.

**3D로 보기**
- 카메라가 없거나 인식이 어려우면 "3D로 보기"를 누릅니다. 같은 서울을 한 손가락으로 돌리고 두 손가락으로 확대해 봅니다. 발표자 따라가기와 요약 패널은 똑같이 동작합니다.

## 4. 문제가 생기면

| 증상 | 조치 |
|---|---|
| 카메라 권한을 거부해 3D로 넘어갔다 | iOS: 설정 > Safari > 카메라를 "허용"으로, 또는 주소창의 "ㅇA" 메뉴 > 웹사이트 설정. Android Chrome: 주소창 자물쇠 > 권한 > 카메라. 그 뒤 "카메라로 보기"를 다시 누릅니다 |
| 그림을 비춰도 인식되지 않는다 | 그림 전체가 폰 화면에 들어오게 하고, 더 가까이(0.5~1m) 가 봅니다. 화면 반사를 피하고, 폰을 그림과 평행하게 듭니다. 발표 화면이 슬라이드 모드(그림 최대)인지 확인합니다 |
| 서울이 보이다가 자꾸 사라진다 | 폰을 천천히 움직이고, 그림 일부가 화면 밖으로 나가지 않게 합니다. 잠깐 놓쳐도 0.8초 동안은 마지막 위치를 유지합니다 |
| 발표자가 바꿔도 폰이 안 따라온다 | 폰 요약 패널의 상태를 봅니다. "직접 보는 중"이면 "라이브로 돌아가기". "연결 끊김"이면 자동으로 다시 붙으니 몇 초 기다리고, 그래도 안 되면 새로고침. 발표자 화면이 "연결됨"인지, 노트북 시계가 자동 설정인지 확인합니다 |
| 지도가 옆으로 눕거나 뒤집혀 보인다 | 폰을 그림과 평행하게 들어 다시 인식시킵니다. 계속 그렇다면 알려 주세요(좌표계 문제) |
| 숫자가 "거래 없음" | 그 법정동 또는 구에 해당 월 유효 거래가 없는 것입니다. 취소된 거래는 통계에서 빼고 건수만 따로 셉니다 |
| 무대(`#/stage`)가 마우스 모드로 바뀌었다, 손짓이 안 먹는다, 소리가 안 난다 | 7절의 "문제가 생기면"을 봅니다. 알림 문구마다 이유가 적혀 있고, 대부분 G로 손 모드를 다시 켜거나 지도 빈 곳을 한 번 클릭하면 됩니다 |

## 5. 보이는 숫자의 뜻

- 출처: 서울 열린데이터광장 부동산 실거래가(매매). 2026년 11월은 신고가 진행 중인 달이라 건수가 계속 늘어납니다. 이 앱의 수치는 2026-11-17 조회 기준 스냅샷입니다.
- 유효 거래: 취소되지 않은 거래. 취소 건은 "거래" 수에서 빼고 별도 집계합니다.
- ㎡당 중앙값: 거래금액(만원) ÷ 건물면적(㎡)의 중앙값. 면적이 0인 거래(일부 단독·다가구)는 ㎡당 통계에서만 빠집니다.
- 최고가: 그 범위에서 가장 큰 거래금액.
- 법정동까지만 표시합니다. 번지, 건물명, 개별 거래는 보여 주지 않습니다.
- 색: 따뜻한 색(주황)일수록 높고, 차가운 색(파랑)일수록 낮습니다. 회색은 자료 없음.

### 조정 파라미터

AR이 흔들리거나 너무 굼뜨게 따라오면, 다시 배포하지 않고 폰 주소창에서 바로 값을 바꿔 볼 수 있습니다. 관객용 주소 끝의 `#/ar` 뒤에 `?`와 값을 붙입니다.

```
<앱 주소>/#/ar?cf=0.0001&beta=0.01&miss=10&alpha=0.18&hold=800
```

- 모두 선택 사항입니다. 0보다 큰 숫자만 적용하고, 그 밖의 값(빈 값, 음수, 0, 글자)은 무시하고 기본값을 씁니다.
- 적용 중인 값은 AR 화면 바텀시트의 구 이름 아래에 "조정값 적용 중: …" 한 줄로 보입니다. 값을 하나도 주지 않으면 이 줄은 나오지 않습니다.
- 주소를 바꾼 뒤에는 "카메라 켜기"를 다시 누릅니다. QR은 값이 붙지 않은 주소를 가리키므로 관객에게는 영향이 없습니다.

| 이름 | 기본값 | 하는 일 |
|---|---|---|
| `cf` | 0.0001 | MindAR One-Euro 필터의 최소 차단 주파수(cycles/ms). 작을수록 덜 흔들리지만 늦게 따라옵니다. |
| `beta` | 0.01 | One-Euro 속도 계수. 작을수록 빠르게 움직여도 덜 흔들립니다(그만큼 끌림이 생깁니다). |
| `warm` | 5 | 그림을 몇 프레임 연속으로 찾아야 "찾음"으로 볼지. |
| `miss` | 10 | 몇 프레임 연속으로 놓쳐야 "놓침"으로 볼지. 크면 잠깐 가려져도 깜빡이지 않습니다. |
| `alpha` | 0.18 | 추종 그룹의 위치 보간 비율(60 Hz 한 프레임당 lerp). 작을수록 부드럽고 느립니다. |
| `ralpha` | 0.18 | 추종 그룹의 회전 보간 비율(60 Hz 한 프레임당 slerp). |
| `dead` | 0.004 | 위치 데드밴드(그림 폭 단위). 이보다 작은 움직임은 무시해 정지 상태의 미세 떨림을 없앱니다. |
| `rdead` | 0.01 | 회전 데드밴드(라디안). |
| `hold` | 800 | 그림을 놓친 뒤 마지막 위치를 유지하는 시간(ms). |

값을 정했으면 기본값 자체를 바꾸는 것은 코드 작업입니다(`frontend/src/ar/smoothing.ts`, `frontend/src/ar/session.ts`).

## 7. 무대 화면 (#/stage)

발표자가 노트북 웹캠 앞에서 손짓으로 프로젝터의 3D 서울을 움직이는 화면입니다. 손바닥이 화면 위 커서가 되고, 구 위에서 주먹을 쥐면 그 구가 들려 올라오며 해설 음성이 나옵니다. 두 손을 펴면 25개 구가 ㎡당 가격순으로 늘어서고, 빈 곳을 주먹으로 잡으면 지도를 지구본처럼 돌릴 수 있습니다. 카메라나 손 인식이 안 되면 같은 일을 마우스와 키로 합니다.

**준비**
- 웹캠이 달린 노트북에서 엽니다. 손 인식은 이 노트북 브라우저 안에서 돕니다.
- 손 인식 모델 파일이 배포에 들어 있어야 합니다(README "무대 모델 받기"). 없으면 시작 화면에 "동작 인식 모델이 없어 마우스로 진행합니다"가 뜨고 마우스로만 진행합니다.
- 카메라에는 발표자 손만 비춥니다. 투표는 카메라에 보이는 손 개수로 세므로, 뒤에 앉은 사람의 손이 화면에 들어오지 않게 노트북 방향을 잡습니다.

**열기**
1. 발표자 화면(`#/host`) 오른쪽 열 맨 아래의 "무대 열기"를 누릅니다("큰 화면 열기"와 "처음으로" 사이). 같은 창이 무대로 바뀝니다. 프로젝터에 보이는 창에서 열고 전체 화면으로 키웁니다.
2. 시작 화면에서 둘 중 하나를 누릅니다. 이 클릭이 해설 소리를 허용하는 역할도 하므로 직접 눌러야 합니다.
   - "무대 시작": 카메라와 손 인식을 켭니다. 브라우저가 카메라 권한을 물으면 허용합니다. "카메라와 동작 인식을 준비하는 중"이 보이는 동안 기다리고, 기다리지 않으려면 "마우스로 계속"을 누릅니다. 화면이 보이는 시간으로 20초가 지나도 준비되지 않으면(권한 창을 늦게 누른 시간도 포함) "동작 인식 준비가 늦어 마우스로 진행합니다 · G로 다시 시도할 수 있어요"와 함께 마우스로 시작합니다.
   - "마우스로 시작": 카메라 없이 마우스와 키로만 진행합니다. 투표는 직접 선택 방식이 됩니다.
3. 무대가 열리면 "무대를 시작합니다. 손을 들어 서울을 움직여 보세요." 해설이 나옵니다. 월과 막대 기준은 발표자 화면에서 고른 것을 이어받고, 관객 폰은 서울 전체 보기로 맞춰집니다.
4. 끝나면 브라우저의 뒤로 가기로 발표자 화면에 돌아갑니다. 떠나는 순간 지도 화면·들어 올린 구 없음 상태를 한 번 보내므로 따라오던 폰이 펼친 화면에 남지 않습니다.

**화면**
- 위: "서울이 선다 · 무대", 월과 막대 기준(예: "2026년 11월 · ㎡당 가격"), 연결 상태. 관객 폰으로 보내는 두 통로가 모두 열려야 "실시간 연결"입니다. "연결 중"이면 몇 초 기다리고, "오프라인 모드"면 관객 폰에 전달되지 않으니 새로고침합니다. 빨간 "발행 실패"는 보내기가 실패했다는 뜻이고, 다음 보내기가 성공하면 사라집니다.
- 가운데: 3D 서울. 손 모드에서는 지름 56px 원형 링이 손을 따라다니는 커서입니다. 커서 아래 구는 테두리가 밝아지고, 주먹을 쥐면 링이 채워집니다. 손이 카메라에서 사라지면 커서도 사라집니다.
- 오른쪽 아래: 웹캠 미리보기. 거울 영상 위에 손 골격(점과 선)이 그려집니다. C로 바꾸거나 숨깁니다.
- 아래 가운데: 해설 자막과 조작 안내 줄. 안내 줄은 입력 방식에 따라 바뀌고, H로 숨깁니다.
  - 손 모드: "주먹: 들어올리기 · 빈 곳 주먹 끌기: 돌리기 · 두 주먹: 돌리기·확대 · 두 손 펴기: 가격순 펼치기 · 브이: 전체 보기 · V: 투표 · M: 음소거"
  - 마우스 모드: "누르고 있기: 들어올리기 · 빈 곳 끌기: 돌리기 · 휠: 확대 · 스페이스: 가격순 펼치기 · Esc: 전체 보기 · V: 투표 · G: 손 모드"

**손짓**

손짓은 약 0.2초(6프레임) 그대로 유지해야 인식됩니다. 주먹을 쥐거나 놓은 뒤, 두 손 펴기·브이 뒤 0.8초 동안은 새 주먹·두 손 펴기·브이를 받지 않습니다(놓기는 언제든 됩니다). 손짓 사이에 1초쯤 둡니다.

| 손짓 | 하는 일 |
|---|---|
| 한 손 펴서 움직이기 | 커서 이동. 손바닥 가운데가 커서가 됩니다. 편 손만으로는 아무것도 켜지지 않습니다 |
| 구 위에서 주먹 | 그 구를 들어올리고 그 구 해설이 나옵니다. 쥐고 있는 동안 떠 있고, 손을 펴거나 카메라 밖으로 빼면 내려앉아 법정동 막대가 자랍니다. 관객 폰도 그 구로 갑니다 |
| 빈 곳에서 주먹 쥐고 좌우로 끌기 | 지도를 지구본처럼 돌립니다(좌우로만, 기울이지 않음). 커서가 화면 끝에서 끝까지 가면 약 반 바퀴입니다. 쥔 채 손을 멈추면 멈추고, 천천히 펴면 그 각도에 남습니다 |
| 빈 곳 주먹을 빠르게 밀며 펴기 | 손을 펴는 순간 직전의 속도로 걸립니다. 밀면서 펴면 놓은 뒤에도 관성으로 돌다가 1~2초에 걸쳐 느려지며 멈춥니다. 다 밀고 멈춘 뒤 펴면 걸리지 않습니다 |
| 관성으로 도는 중에 주먹 | 어디서 쥐든 그 자리에서 바로 멈춥니다(놓은 직후에도 기다릴 필요 없음). 이 주먹은 잡기 전용이라 구 위에서 쥐어도 구를 들지 않습니다. 쥔 채 끌면 이어서 돌립니다 |
| 두 손 주먹 | 두 주먹을 함께 좌우로 옮기면 돌리고, 두 주먹 사이를 벌리면 확대, 모으면 축소합니다(0.7~1.6배). 한 손 주먹으로 구를 든 채 다른 손도 주먹을 쥐면 돌리기가 우선이라, 든 구는 고르지 않은 채 제자리로 내려가고 지도가 돌기 시작합니다(펼친 화면에서는 두 주먹이 아무 일도 하지 않습니다). 한 손을 펴거나 내리면 0.2~0.3초 뒤에 끝나므로, 한 손이 잠깐 빠졌다가 0.3초 안에 돌아오면 이어서 돌립니다 |
| 두 손 펴기 | 25개 구가 ㎡당 가격순으로 한 줄로 펼쳐집니다(왼쪽이 가장 비쌈). 다시 두 손을 펴면 지도로 돌아옵니다. 펼친 화면에서 구 위 주먹으로 들었다 놓으면 지도로 돌아가 그 구가 솟아오릅니다 |
| 브이 | 전체 보기. 들어 올린 구와 고른 구를 풀고 지도로 돌아갑니다. 관객 폰도 전체 보기로 갑니다 |

**돌리기·확대의 규칙**
- 돌리기와 확대는 지도 화면에서만 됩니다. 펼친 화면과 투표 중에는 돌거나 확대되지 않습니다. 한 손 주먹(마우스 누르기)으로 구를 든 동안에는 한 손 돌리기와 휠 확대가 되지 않고, 두 주먹만 구를 내려놓고 돌리기를 시작합니다.
- 큰 화면은 무대를 따라오는 동안 스스로 돌지 않고 무대의 각도와 배율을 그대로 따릅니다. 무대 소식이 30초 끊기면 원래대로(정면·1배, 자동 회전 재개) 돌아갑니다.
- 두 주먹으로 들고 있던 구를 내려놓을 때 그 구의 해설도 멈춥니다.
- 주먹으로 돌리는 동안에는 커서 아래 구가 밝아지지 않습니다. 관성으로 도는 중의 주먹은 멈추기만 하므로, 구를 들려면 멈춘 뒤 다시 쥡니다.
- 돌려 놓은 각도와 확대는 그대로 남습니다. 그 상태에서 구를 들어올릴 수도 있습니다.
- 두 손 펴기(펼치기로 들어갈 때), 브이, V(투표 시작), 손·마우스 모드 전환(G 또는 자동 전환) 때는 약 0.6초에 걸쳐 정면·1배로 돌아옵니다(움직임 줄이기 설정이면 바로). 펼친 화면의 "왼쪽이 가장 비쌉니다"가 늘 맞고, 투표 화면이 돌아간 채 보이지 않게 하려는 것입니다.

**마우스와 키**

손 모드에서도 마우스와 키는 항상 됩니다(발표 중 비상 조작). 한글 입력 상태여도 같은 자리의 키로 동작합니다. 키를 누르고 있어도 반복되지 않습니다(↑/↓만 반복).

| 입력 | 하는 일 |
|---|---|
| 마우스 움직이기 | 커서. 아래 구가 밝아집니다 |
| 구 위에서 누르고 있기 | 주먹과 같습니다. 누르는 동안 들어올리고, 떼면 내려앉습니다 |
| 빈 곳 누르고 끌기 | 돌리기. 빠르게 끌다 떼면 관성으로 돌고, 도는 중에 클릭하면 멈춥니다(구를 들지 않음) |
| 휠 | 확대·축소(0.7~1.6배). 스크롤이 쌓여 100 단위마다 한 단계씩 바뀝니다(100 단위로 움직이는 휠은 한 칸에 한 단계, 한 칸이 줄 단위로 움직이는 장치는 약 2칸에 한 단계, 트랙패드는 천천히 쓸어도 쌓입니다). 지도 화면에서만 되고, 구를 든 동안과 투표 중에는 되지 않습니다 |
| 스페이스 | 두 손 펴기와 같습니다(펼치기 ↔ 지도) |
| Esc | 브이와 같습니다(전체 보기) |
| V | 투표 시작. 진행 중에 누르면 취소 |
| N | 투표 중 입력 방식 바꾸기(카메라 ↔ 직접 선택) |
| 0~6 | 투표 중 지금 후보의 손 개수 고르기. 집계 확인 중에는 고른 줄 |
| ↑ / ↓ | 집계 확인 중 고칠 줄 고르기 |
| Enter | 집계 확인 중 확정 |
| G | 손 모드 ↔ 마우스 모드. 카메라가 꺼져 있었으면 다시 켜 봅니다(최대 20초) |
| M | 해설 소리 끄기·켜기. 자막은 그대로 나옵니다 |
| C | 웹캠 미리보기: 영상+골격 → 골격만 → 숨김 → 다시 영상+골격 |
| D | 진단 표시(왼쪽 아래): 프레임, 손 개수, 제스처와 점수, 커서 좌표, 모델 로드 시간, 연산(GPU/CPU), 입력 |
| H | 안내 줄 숨기기·보이기 |
| P | 막대 기준 바꾸기(㎡당 가격 ↔ 거래 건수). 관객 폰도 따라옵니다. 펼치기 순서는 늘 ㎡당 가격순입니다 |
| ← / → | 이전·다음 달. 들어 있는 달 안에서만 움직이고, 관객 폰도 따라옵니다 |

**투표**

카메라에 보이는 손 개수로 후보 세 곳 중 한 곳을 뽑습니다. 카메라에는 발표자 손만 비추는 것이 전제라, 관객에게 물은 뒤 발표자가 손 0~2개를 들어 표를 대신 보여 줍니다(한 후보 최대 6손).

1. V를 누르면 "투표를 시작합니다. 보고 싶은 구에 손을 들어 주세요." 해설과 함께 투표 패널이 뜹니다. 들고 있던 구는 내려가고, 돌려 놓은 지도는 정면으로 돌아옵니다.
   - 후보는 기본으로 지금 달 ㎡당 중앙값 1위·13위·25위 구(비싼 곳·중간·싼 곳)입니다. 막대 기준과는 상관없습니다.
   - 후보를 정하려면 무대를 `…/#/stage?vote=강남구,마포구,노원구`처럼 열고 시작합니다. 틀린 이름은 무시하고 기본 후보로 채웁니다.
2. 후보마다 "강남구 보고 싶은 분, 손 들어 주세요" 안내가 나온 뒤 손을 셉니다. 패널에는 세 후보가 줄로 보이고, 아직 안 온 후보는 "(대기)"입니다.
   - 카메라 방식: 안내가 끝나면 5초 동안 카메라에 보이는 손을 셉니다. 패널 아래 "카메라: 지금 2손"처럼 지금 개수가 보입니다. 0.5초 이상 같은 개수로 이어진 값 중 가장 큰 값이 표가 되므로, 손을 들면 잠깐 그대로 둡니다. 5초 동안 개수가 한 번도 안정되지 않으면 0표로 넘기지 않고 "손이 인식되지 않았어요 · 개수를 골라 주세요"를 띄워 고를 때까지 기다립니다.
   - 직접 선택 방식: 타이머가 없습니다. 후보 줄의 0~6 버튼이나 숫자키로 고르면 1초 뒤 다음 후보로 갑니다.
   - 방식은 패널 아래 "카메라" / "직접 선택" 버튼이나 N으로 언제든 바꿉니다. 마우스 모드면 자동으로 직접 선택이 됩니다.
   - 카메라가 센 값은 언제든 숫자로 덮어쓸 수 있습니다. 직접 고른 값에는 "직접", 카메라 값에는 "카메라"가 붙습니다. 지나간 후보도 고칠 수 있습니다.
3. 세 후보가 끝나면 "집계 확인 · 고칠 곳이 있으면 개수를 누르세요"가 3초 동안 뜬 뒤 자동으로 확정됩니다. 그 사이 어느 줄이든 고치면 자동 확정이 멈추고 Enter나 "확정 Enter" 버튼을 기다립니다. 키보드로는 ↑/↓로 줄을 고르고 숫자키로 고칩니다.
4. 확정되면 가장 많이 받은 구가 뽑힙니다(동점이면 앞 후보). "2표로 강남구가 뽑혔습니다." 해설에 이어 그 구 해설이 나오고, 지도에서 그 구가 솟아오르며 관객 폰도 그 구로 갑니다. 아무도 손을 들지 않았으면 "아무도 손을 들지 않아 ○○구로 갑니다"와 함께 첫 후보로 갑니다. 패널의 결과("강남구 선정")는 6초 뒤 사라지고, 관객 폰에는 "투표 결과 강남구 2표 · 마포구 1표 · 노원구 0표" 한 줄이 6초 뜹니다.

- 투표 중에는 주먹·두 손 펴기·브이·두 주먹이 꺼집니다(스페이스, Esc, 마우스 누르기도 같음). 결과가 뜬 직후 1.5초도 손짓을 받지 않습니다(투표 내내 쥐고 있던 주먹이 결과를 지우지 않게).
- 진행 중에 V를 다시 누르면 투표가 취소되고 해설도 멈춥니다.

**관객 폰과 큰 화면이 따라오는 것**

| 무대에서 한 일 | 관객 폰 `#/3d` (라이브) | 큰 화면 `#/3d?stage=1` |
|---|---|---|
| 구 선택, 월, 막대 기준 | 따라옴 | 따라옴 |
| 들어올리기, 펼치기 | 따라옴 | 따라옴 |
| 투표 결과 | 한 줄 6초 | 한 줄 6초 |
| 돌리기, 확대 | 따라오지 않음. 각자 손가락으로 돌려 봅니다 | 부드럽게 따라옴 |

- 큰 화면을 다른 창이나 다른 화면에 띄워 두었다면 무대에서 돌린 각도와 확대 배율도 따라옵니다. 도는 동안 초당 최대 5번, 멈출 때 한 번 더 보내고, 큰 화면이 그 사이를 부드럽게 메우므로 무대보다 살짝 늦게 따라옵니다.
- 폰이 "직접 보는 중"이면 들어올리기·펼치기를 따라오지 않습니다("라이브로 돌아가기"로 복귀). 투표 결과 한 줄은 그래도 뜹니다.
- AR(`#/ar`)로 보던 폰: 무대가 프로젝터를 차지하면 비출 그림이 없어 추적을 잃습니다. 무대 소식을 받으면 "무대 진행 중 · 3D로 따라가기" 배너가 뜨고, 누르면 3D로 넘어가 무대를 따라갑니다.
- 10초마다 같은 상태를 다시 보내므로 늦게 들어온 폰도 따라옵니다. 무대 탭을 닫거나 노트북이 잠들어 30초 동안 소식이 없으면 폰은 지도로, 큰 화면은 지도·정면·1배로 돌아가고 AR 배너도 사라집니다.

**해설과 소리**
- 해설은 미리 만들어 둔 음성 파일입니다(집계 수치로 Amazon Bedrock이 문장을 쓰고 Amazon Polly 서연 목소리로 녹음). 무대에서는 재생만 하고, 재생 중에는 아래 가운데에 자막이 함께 나옵니다.
- 새 동작의 해설은 앞 해설을 끊고 바로 나옵니다. 투표 안내는 끊기지 않습니다.
- 구 해설은 2026년 11월 것만 실려 있습니다. 다른 달에서 구를 들면 그 구 해설 없이 진행됩니다.
- M으로 소리만 끕니다("해설 소리를 껐습니다"). 자막과 진행은 그대로입니다.
- 브라우저가 소리를 막으면 "소리가 막혔습니다 · 화면을 한 번 눌러 주세요" 알림이 뜹니다. 지도 빈 곳을 한 번 클릭하면 다시 풀어 봅니다.

**리허설**
- 웹캠 앞 0.5~1m, 손 뒤는 단색 배경, 역광은 피합니다. D로 프레임이 20 fps 이상인지 봅니다.
- 주먹·두 손 펴기·브이를 각각 3번씩 해 봅니다. 주먹을 쥔 채 아주 빠르게 휘두르면 손을 놓친 것으로 보고 0.3초 뒤 놓습니다.
- 돌리기: 빈 곳 주먹으로 천천히 돌리다 멈추기, 빠르게 밀고 놓아 관성 보기, 도는 중 구 위에서 주먹을 쥐어 멈추기만 되는지(구가 들리면 안 됨), 두 주먹으로 벌리고 모으기, 구를 든 채 다른 손 주먹을 쥐면 구가 내려가고 돌기 시작하는 것. 휙 미는 동작은 손을 펴면서 밀어야 관성이 걸리는지, 관성이 도는 중 놓은 지 0.3초 뒤에도 바로 주먹으로 잡히는지 봅니다. 그다음 두 손 펴기·브이·V에서 정면으로 돌아오는지 봅니다. 큰 화면을 함께 띄웠다면 무대 각도·배율을 따라오는지, 무대가 도는 동안 큰 화면이 혼자 돌지 않는지, 무대 탭을 닫고 30초 뒤 원래대로 돌아오는지도 봅니다.
- 커서를 빠르게 움직이는 동안 지도가 저절로 돌지 않는지 봅니다. 주먹이 인식될 때만 돌아야 합니다.
- 투표: 손 0·1·2개, 숫자로 고치기, 집계 확인에서 고치기, N으로 방식 바꾸기, 마우스 모드로 투표.
- 소리: 시작 버튼을 누른 뒤 첫 해설이 들리는지 봅니다.
- Windows 한국어 입력기를 켠 채 V·G·M·N·P를 한 번씩 눌러 봅니다.
- 발표 순서 예: 무대 시작 → 두 손 펴서 가격순 → 다시 두 손 펴서 지도 → 빈 곳 주먹으로 돌려 보기 → 브이로 정면 → 주먹으로 강남구 → 브이 → V 투표 → 뽑힌 구 해설.

**문제가 생기면**

| 증상 | 이유와 조치 |
|---|---|
| 시작 화면에 "동작 인식 모델이 없어 마우스로 진행합니다" | 배포에 모델 파일이 없습니다. README "무대 모델 받기"대로 받은 뒤 6절 명령으로 다시 빌드·배포합니다. 그때까지는 마우스로 진행합니다 |
| "카메라 권한이 거부되어 마우스로 진행합니다" | 주소창 자물쇠(사이트 설정)에서 카메라를 허용하고 G를 누르면 손 모드를 다시 시도합니다 |
| "카메라를 찾지 못해 마우스로 진행합니다" | 웹캠 연결과, 화상회의 앱 같은 다른 프로그램이 카메라를 쓰고 있지 않은지 확인한 뒤 G |
| "동작 인식을 시작하지 못해 마우스로 진행합니다", "이 브라우저는 동작 인식을 지원하지 않아 마우스로 진행합니다" | 손 인식 엔진을 띄우지 못했습니다. 새로고침하고, 그래도 안 되면 다른 브라우저로 열거나 마우스로 진행합니다 |
| "동작 인식 준비가 늦어 마우스로 진행합니다 · G로 다시 시도할 수 있어요" | 손 인식 준비가 20초 안에 끝나지 않았습니다. 권한 창을 바로 허용했는지 보고 G로 다시 시도합니다 |
| "카메라 영상이 끊겨 마우스로 바꿨습니다 · G로 다시 시도할 수 있어요" | 손 모드에서 카메라 영상이 1.5초 동안 들어오지 않았습니다(웹캠이 빠짐, 다른 프로그램이 카메라를 가져감 등). 들고 있던 구는 내려놓습니다. 원인을 없앤 뒤 G |
| "손 인식이 계속 실패해 마우스로 바꿨습니다. G로 다시 시도할 수 있어요" | 인식이 약 2초 연속 실패했습니다. G로 다시 시도하고, 되풀이되면 새로고침합니다 |
| "소리가 막혔습니다 · 화면을 한 번 눌러 주세요" | 브라우저가 소리 재생을 막았습니다. 지도 빈 곳을 한 번 클릭하면 다시 풀어 봅니다. 그동안에도 자막은 나옵니다 |
| 소리가 안 나는데 알림도 없다 | M으로 꺼 두지 않았는지("해설 소리를 껐습니다"), 노트북 볼륨과 출력 장치를 봅니다 |
| 주먹을 쥐었는데 구가 안 들리고 지도가 돈다 | 커서가 구 밖(빈 곳)에 있었습니다. 커서 아래 구가 밝아진 것을 보고 쥡니다. 관성으로 도는 중에는 주먹이 멈추기만 하니, 멈춘 뒤 다시 쥡니다 |
| 돌리기·확대가 안 된다 | 지도 화면에서만 됩니다. 펼친 화면이면 두 손 펴기(스페이스)나 브이(Esc)로 지도로 돌아옵니다. 투표 중에는 돌거나 확대되지 않습니다. 한 손 주먹으로 구를 든 동안에는 한 손 돌리기와 휠 확대가 안 되니, 구를 놓은 뒤 다시 하거나 두 주먹을 쥡니다(든 구는 고르지 않은 채 내려갑니다) |
| 두 손 펴기나 두 주먹이 안 먹는다 | 카메라에 손이 정확히 두 개만 보여야 합니다. 두 손 펴기는 편 채로 두면 한 번만 바뀌니, 손을 내렸다가 다시 폅니다. 주먹을 놓자마자 편 두 손도 펼치기로 치지 않으니 손 모양을 한 번 바꾼 뒤 폅니다 |
| 화면이 저절로 정면으로 돌아왔다 | 펼치기·브이·투표 시작·모드 전환(마우스로 자동 전환 포함) 때는 정면·1배로 돌아오는 것이 정상입니다 |
| 위에 "오프라인 모드" 또는 빨간 "발행 실패" | 관객 폰에 전달되지 않고 있습니다. 노트북 네트워크를 확인하고 새로고침합니다. 무대 자체는 계속 움직입니다 |
| "이 기기에서는 3D를 그릴 수 없습니다. 투표와 해설은 그대로 진행할 수 있습니다." | 브라우저가 3D(WebGL)를 쓰지 못합니다. 브라우저 설정에서 하드웨어 가속을 켜고 새로고침합니다 |
| 관객 폰이 무대를 안 따라온다 | `#/3d` 폰이 "직접 보는 중"이면 "라이브로 돌아가기", AR 폰이면 "무대 진행 중 · 3D로 따라가기" 배너를 누릅니다. 돌리기·확대는 원래 폰에 전달되지 않습니다 |

**개인정보와 외부 호출**
- 카메라 영상, 손 좌표, 골격은 노트북 브라우저 안에서만 처리하고 저장하거나 보내지 않습니다. 미리보기도 이 화면에만 그립니다.
- 밖으로 나가는 것은 장면 상태뿐입니다: 월·구 이름·막대 기준, 지도/펼치기, 들어 올린 구, 투표 후보와 손 개수, 돌린 각도와 확대 배율 두 숫자. 보내기 전에 정해진 항목 밖의 값이 들어 있으면 보내지 않습니다.
- 손 인식 모델 파일은 배포 전에 한 번만 받아 앱과 함께 올립니다(README "무대 모델 받기"). 실행 중에는 모델과 인식 엔진(wasm)을 앱과 같은 주소에서 읽고, Google을 포함한 외부 서버를 부르지 않습니다. 연결하는 곳은 앱 주소(정적 파일)와 관객 폰 전달용 AppSync Events뿐입니다.
- 해설도 미리 만든 음성 파일을 재생할 뿐, 무대에서 AI를 새로 부르지 않습니다.

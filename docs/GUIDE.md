# 서울이 선다 사용 가이드

발표 화면의 그림을 폰 카메라로 비추면 그림 위에 서울 25개 자치구가 3D로 서고, 발표자가 고른 구가 솟아오르며 법정동별 실거래 막대가 자랍니다. 발표자의 선택은 모든 관객 폰에 1초 안에 같이 바뀝니다.

| 역할 | 기기 | 주소 |
|---|---|---|
| 발표자 | 노트북 + 프로젝터(또는 큰 모니터) | https://d2zgenhitcakex.cloudfront.net/#/host |
| 관객 | 폰 (iOS Safari, Android Chrome) | https://d2zgenhitcakex.cloudfront.net (화면의 QR로 열림) |
| 카메라 없이 보기 | 아무 기기 | https://d2zgenhitcakex.cloudfront.net/#/3d |

## 1. 전체 진행 순서

```
발표자                                    관객
──────────────────────────────            ──────────────────────────────
① 노트북에서 #/host 열기
② "슬라이드 모드" (S 키)
   → 화면에 그림 + QR + 제목만 남음
                                           ③ 폰 카메라로 QR 찍기 → 페이지 열림
                                           ④ "카메라 켜기" → 권한 허용
                                           ⑤ 발표 화면의 그림을 폰 화면에 담기
                                              → 그림 위에 서울 등장
⑥ Esc 로 슬라이드 모드 끝내기
⑦ 월 · 막대 기준 · 자치구 선택
   → 모든 폰이 1초 안에 따라옴             ⑧ 아래 요약에서 숫자 읽기
                                              흔들리면 "화면 고정"
                                           ⑨ 직접 다른 구를 보고 싶으면 아래 선택
                                              → "직접 보는 중", "라이브로 돌아가기"로 복귀
⑩ "전체 보기"로 마무리
```

발표 중에는 ②의 슬라이드 모드와 ⑦의 조작 화면을 S / Esc 로 오가면 됩니다. 조작 화면에서도 그림과 QR은 왼쪽에 그대로 보이므로, 프로젝터에 조작 화면을 띄운 채 진행해도 관객은 그림을 비출 수 있습니다.

## 2. 발표자 화면 (노트북)

`#/host` 를 열면 두 열로 나뉩니다.

**왼쪽 (관객에게 보여 줄 화면)**
- 제목 "서울이 선다"
- AR 인식용 그림. 관객이 폰 카메라로 비추는 대상입니다.
- QR 코드. 지금 열려 있는 주소로 자동 생성되므로 따로 만들 필요가 없습니다. 안내 문구 "폰 카메라로 QR을 찍고, 열린 화면을 왼쪽 그림에 비춰 보세요"가 함께 뜹니다.

**오른쪽 (발표자 조정)**
- 연결 상태. "연결됨: 바꾸면 관객 폰에 바로 반영됩니다"가 보여야 정상입니다. "연결 중"이면 몇 초 기다리고, "연결 안 됨"이면 새로고침합니다.
- 월. 지금 들어 있는 데이터는 2026년 11월 한 달입니다.
- 막대 기준. "㎡당 가격" 또는 "거래 건수". 구 아래 숫자의 뜻이 함께 바뀝니다.
- 자치구. 25개 구 버튼. 누르면 그 구가 솟아오르고 법정동 막대가 자랍니다. "전체 보기"를 누르면 25개 구를 색으로만 비교하는 전체 화면으로 돌아갑니다.
- 슬라이드 모드 버튼. S 키와 같습니다. 전체 화면으로 들어가 그림, QR, 제목만 남깁니다. Esc 또는 "슬라이드 모드 끝내기"로 나옵니다.
- "처음으로". 랜딩으로 돌아갑니다.

**동작 원리**
- 월, 기준, 구를 바꿀 때마다 관객 폰으로 상태가 전송됩니다. 10초마다 같은 상태를 다시 보내므로 늦게 들어온 관객도 자동으로 따라옵니다.
- 전송이 실패하면 "관객 화면에 보내지 못했습니다. 연결 상태를 확인해 주세요."라는 알림이 뜹니다.

**발표 팁**
- 그림이 화면에서 클수록 멀리서도 인식됩니다. 슬라이드 모드에서는 그림이 가장 크게 나옵니다. 프로젝터라면 그림 한 변이 40cm 이상이면 2~3m 거리에서도 잡힙니다.
- 화면 밝기를 최대로, 조명 반사가 그림 위에 생기지 않게 합니다.
- 노트북 시계가 자동 설정(인터넷 시간)이어야 합니다. 폰보다 30초 이상 앞서 있으면 메시지가 위조로 간주되어 무시됩니다.
- 리허설 때 폰 한 대로 ③~⑨를 한 번 끝까지 해 봅니다.

## 3. 관객 화면 (폰)

**열기**
1. 발표 화면의 QR을 폰 카메라로 찍습니다. 설치 없이 브라우저로 열립니다.
2. 랜딩에서 "카메라로 보기"를 누릅니다. 카메라를 쓸 수 없는 기기면 "3D로 보기"로 넘어갑니다.
3. "카메라 켜기"를 누르고 브라우저의 카메라 권한을 허용합니다. 카메라 영상은 폰 밖으로 전송되지 않습니다.
4. "슬라이드의 그림을 비춰 주세요"가 뜨면 발표 화면의 그림이 폰 화면에 다 들어오게 폰을 듭니다. 거리는 보통 0.5~2m, 그림이 폰 화면의 절반 이상을 차지하면 가장 잘 잡힙니다.
5. 인식되면 그림 위에 서울이 섭니다. 발표자가 고른 구가 솟아 있고 법정동 막대가 자랍니다.

**읽기 (아래 요약 패널)**
- 맨 위: 지금 보는 지역(서울 전체 또는 구 이름)과 월, 그리고 상태 표시. "라이브: 발표자 화면을 따라가는 중"이 기본입니다.
- 숫자: ㎡당 중앙값(만원), 거래 건수, 최고가. 구를 보고 있으면 법정동 상위 5개 목록이 함께 나옵니다. 3D 라벨이 흔들려도 숫자는 여기서 읽습니다.
- "가격 / 건수" 토글: 막대 기준을 폰에서만 바꿔 볼 수 있습니다.
- "막대와 색의 기준": 색 범례와 정의가 펼쳐집니다.

**흔들릴 때: 화면 고정**
- "화면 고정"을 누르면 카메라 영상과 추적이 멈추고 마지막 장면이 그대로 남아 숫자를 차분히 읽을 수 있습니다. 상태가 "고정됨"으로 바뀌고 버튼은 "다시 추적"이 됩니다.
- 발표자가 구를 바꾸면 고정 중에도 숫자와 막대는 새 값으로 갱신됩니다. 장면 위치만 고정됩니다.
- "다시 추적"을 누르면 카메라가 다시 켜집니다.

**직접 둘러보기**
- 요약 패널의 자치구, 월 선택을 직접 바꾸면 "직접 보는 중"으로 바뀌고 발표자 선택을 따라가지 않습니다.
- "라이브로 돌아가기"를 누르면 다시 발표자 화면을 따라갑니다.

**3D로 보기**
- 카메라가 없거나 인식이 어려우면 "3D로 보기"를 누릅니다. 같은 서울을 한 손가락으로 돌리고 두 손가락으로 확대해 봅니다. 발표자 따라가기와 요약 패널은 똑같이 동작합니다.

## 4. 문제가 생기면

| 증상 | 조치 |
|---|---|
| 카메라 권한을 거부해 3D로 넘어갔다 | iOS: 설정 > Safari > 카메라를 "허용"으로, 또는 주소창의 "ㅇA" 메뉴 > 웹사이트 설정. Android Chrome: 주소창 자물쇠 > 권한 > 카메라. 그 뒤 "카메라로 보기"를 다시 누릅니다 |
| 그림을 비춰도 인식되지 않는다 | 그림 전체가 폰 화면에 들어오게 하고, 더 가까이(0.5~1m) 가 봅니다. 화면 반사를 피하고, 폰을 그림과 평행하게 듭니다. 발표 화면이 슬라이드 모드(그림 최대)인지 확인합니다 |
| 서울이 보이다가 자꾸 사라진다 | 폰을 천천히 움직이고, 그림 일부가 화면 밖으로 나가지 않게 합니다. 잠깐 놓쳐도 0.8초 동안은 마지막 위치를 유지합니다 |
| 발표자가 바꿔도 폰이 안 따라온다 | 폰 요약 패널의 상태를 봅니다. "직접 보는 중"이면 "라이브로 돌아가기". "연결 끊김"이면 자동으로 다시 붙으니 몇 초 기다리고, 그래도 안 되면 새로고침. 발표자 화면이 "연결됨"인지, 노트북 시계가 자동 설정인지 확인합니다 |
| 지도가 옆으로 눕거나 뒤집혀 보인다 | 폰을 그림과 평행하게 들어 다시 인식시킵니다. 계속 그렇다면 알려 주세요(좌표계 문제) |
| 숫자가 "거래 없음" | 그 법정동 또는 구에 해당 월 유효 거래가 없는 것입니다. 취소된 거래는 통계에서 빼고 건수만 따로 셉니다 |

## 5. 보이는 숫자의 뜻

- 출처: 서울 열린데이터광장 부동산 실거래가(매매). 2026년 11월은 신고가 진행 중인 달이라 건수가 계속 늘어납니다. 이 앱의 수치는 2026-11-17 조회 기준 스냅샷입니다.
- 유효 거래: 취소되지 않은 거래. 취소 건은 "거래" 수에서 빼고 별도 집계합니다.
- ㎡당 중앙값: 거래금액(만원) ÷ 건물면적(㎡)의 중앙값. 면적이 0인 거래(일부 단독·다가구)는 ㎡당 통계에서만 빠집니다.
- 최고가: 그 범위에서 가장 큰 거래금액.
- 법정동까지만 표시합니다. 번지, 건물명, 개별 거래는 보여 주지 않습니다.
- 색: 따뜻한 색(주황)일수록 높고, 차가운 색(파랑)일수록 낮습니다. 회색은 자료 없음.

## 6. 운영 메모

- 발표가 끝나면 비용과 공개 키를 정리하기 위해 스택을 내립니다.

```bash
cd ~/claude-lab/seoul-ar/infra && npx cdk destroy
```

- 다시 올릴 때는 프론트를 빌드한 뒤 배포합니다.

```bash
cd ~/claude-lab/seoul-ar/frontend && npx vite build
cd ~/claude-lab/seoul-ar/infra && npx cdk deploy --require-approval never --outputs-file cdk-outputs.json
```

- 알려진 제약: 지금 버전은 주소를 아는 사람이 발표자 화면을 열어 상태를 바꿀 수 있습니다(발표자 암호는 후속 작업). 데이터는 2026년 11월 한 달입니다.

### 조정 파라미터

AR이 흔들리거나 너무 굼뜨게 따라오면, 다시 배포하지 않고 폰 주소창에서 바로 값을 바꿔 볼 수 있습니다. 관객용 주소 끝의 `#/ar` 뒤에 `?`와 값을 붙입니다.

```
<앱 주소>/#/ar?cf=0.0001&beta=0.01&miss=10&alpha=0.18&hold=800
```

- 모두 선택 사항입니다. 0보다 큰 숫자만 적용하고, 그 밖의 값(빈 값, 음수, 0, 글자)은 무시하고 기본값을 씁니다.
- 적용 중인 값은 AR 화면 바텀시트의 구 이름 아래에 "조정값 적용 중: …" 한 줄로 보입니다. 값을 하나도 주지 않으면 이 줄은 나오지 않습니다.
- 주소를 바꾼 뒤에는 "카메라 켜기"를 다시 누릅니다. QR은 값이 붙지 않은 주소를 가리키므로 관객에게는 영향이 없습니다.

| 이름 | 기본값 | 하는 일 |
|---|---|---|
| `cf` | 0.0001 | MindAR One-Euro 필터의 최소 차단 주파수(cycles/ms). 작을수록 덜 흔들리지만 늦게 따라옵니다. |
| `beta` | 0.01 | One-Euro 속도 계수. 작을수록 빠르게 움직여도 덜 흔들립니다(그만큼 끌림이 생깁니다). |
| `warm` | 5 | 그림을 몇 프레임 연속으로 찾아야 "찾음"으로 볼지. |
| `miss` | 10 | 몇 프레임 연속으로 놓쳐야 "놓침"으로 볼지. 크면 잠깐 가려져도 깜빡이지 않습니다. |
| `alpha` | 0.18 | 추종 그룹의 위치 보간 비율(60 Hz 한 프레임당 lerp). 작을수록 부드럽고 느립니다. |
| `ralpha` | 0.18 | 추종 그룹의 회전 보간 비율(60 Hz 한 프레임당 slerp). |
| `dead` | 0.004 | 위치 데드밴드(그림 폭 단위). 이보다 작은 움직임은 무시해 정지 상태의 미세 떨림을 없앱니다. |
| `rdead` | 0.01 | 회전 데드밴드(라디안). |
| `hold` | 800 | 그림을 놓친 뒤 마지막 위치를 유지하는 시간(ms). |

값을 정했으면 기본값 자체를 바꾸는 것은 코드 작업입니다(`frontend/src/ar/smoothing.ts`, `frontend/src/ar/session.ts`).

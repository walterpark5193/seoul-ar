# 서울이 선다 (seoul-ar) 설계

2026-11-17. 대상: `~/claude-lab/seoul-ar/` 새 저장소. AWS 캡스톤 자유 프로젝트. 사용자 선택: 두 번째 아이디어 목록의 C "슬라이드 위에 서는 서울(관객 폰 AR)". 실행 방식은 사용자 지시로 "최대 속도, 허용된 모든 서브에이전트와 포크를 병렬로".

## 1. 의도와 이유

발표 화면(또는 발표자 노트북의 호스트 화면)에 그림 한 장이 떠 있다. 관객이 폰 카메라로 그 그림을 비추면 그림 위에 서울 25개 자치구가 3D로 서고, 발표자가 고른 자치구가 솟아오르며 법정동별 실거래 막대가 자란다. 발표자가 호스트 화면에서 다른 구를 누르면 모든 관객의 폰에서 동시에 바뀐다. 데이터는 서울 열린데이터광장의 실제 매매 실거래다.

왜: 일반 청중에게 "내 폰 화면 안에 서울이 서 있다"는 장면은 설명 없이 1초 안에 전달되는 와우다. 각자 찍어서 공유할 수 있는 장면이기도 하다. 캡스톤 트랙 B에서 만든 seoul-realestate MCP와 데이터 규칙(법정동까지만, 만원·㎡)이 그대로 데이터 축이 된다.

## 2. 목표, 비목표, 실패 조건

목표
- iOS Safari와 Android Chrome에서 설치 없이 URL만으로 AR이 뜬다. 카메라가 안 되면 같은 3D를 손가락으로 돌려보는 화면으로 자동 폴백한다.
- 발표자 호스트 화면: 마커 그림과 QR, 월·자치구·지표 선택. 선택이 1초 안에 모든 폰에 반영된다(AppSync Events).
- 3D 서울: 25개 구 윤곽 돌출, 선택 구 상승, 법정동 막대(지표: ㎡당 중앙값 또는 거래 건수), 색은 순차 팔레트, 라벨은 한글.
- 실제 데이터 스냅샷 3개월(202609, 202610, 202611)을 빌드 시 포함한다. 라이브 갱신은 비목표.
- 모던 디자인: 어두운 밤 도시 톤, 시스템 한글 산세리프, 유리 패널 바텀시트, 과장된 장식 없음.
- CDK 한 번으로 S3(비공개)+CloudFront(OAC)+AppSync Events가 배포되고 `config.json`이 배포 시 자동 생성된다.

비목표
- 라이브 데이터 갱신 Lambda, 사용자 계정, 서버 측 렌더링, 네이티브 앱, WebXR.
- 법정동 경계 지도. 법정동 막대는 선택 구 영역 안에 정렬 격자로 세운다(경계 데이터 없이도 동작).
- 발표자 인증. 호스트 페이지는 URL을 아는 사람이 쓸 수 있다(데모 한정, 아래 제약 참고).

실패 조건
- 결과물에 본번, 부번, 건물명, 행 단위 거래 데이터, API 키가 들어간다.
- 외부 CDN, 외부 폰트, 런타임 외부 호출(AWS 엔드포인트 제외)이 있다.
- 카메라 거부나 미지원에서 빈 화면이 나온다(반드시 3D 화면으로 폴백).
- 전형적인 AI 생성 페이지 티: 카드 남발, 같은 그림자, ALL CAPS 라벨, 섹션마다 페이드인.

## 3. 제약

- 리전 us-east-1 고정(조직 SCP가 ap-northeast-2 CloudFormation을 거부). 계정 557395122774.
- 이 머신(aarch64, node 24, python 3.14)에는 브라우저가 없다. 확인은 vitest, 빌드, CDK 테스트, 가능하면 헤드리스 크로미움 스크린샷, 최종은 사용자가 CloudFront URL에서 한다.
- 이 세션에는 my-kit 플러그인의 가드가 켜져 있다. Bash와 WebFetch의 입력 문자열에 `http(s)://`가 들어가면 openapi.seoul.go.kr 외에는 차단된다. 따라서 명령문에 주소를 쓰지 않는다. 외부 파일 다운로드(자치구 GeoJSON)는 사용자가 직접 한다. 우회하지 않는다.
- 데이터 규칙(캡스톤 트랙 B 계승): 금액 만원, 면적 ㎡, 법정동까지만, 본번·부번·건물명 미사용, API 키는 파일·명령·커밋·프롬프트에 쓰지 않는다. 데이터는 이 세션의 MCP 도구 search_trades로만 받는다(한 호출 최대 1000건).
- 서울 API 원자료(건물명 포함)는 `tools/data/raw/`에만 두고 git에서 제외한다.
- 글꼴: "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif. 외부 로드 없음.
- 접근성: 색만으로 구분하지 않는다(라벨·수치 병기), `prefers-reduced-motion`에서 자동 회전과 성장 애니메이션 정지, 명도 대비 4.5:1.

## 4. 검토한 접근

### 4.1 AR 추적 방식

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. MindAR 자연 이미지 추적 | 그림 자체를 타깃으로 컴파일(.mind) | 마커가 디자인된 그림처럼 보임, iOS Safari 동작 | 타깃 컴파일 도구 필요(브라우저 없는 머신에서 Node 또는 헤드리스로) |
| B. AR.js 패턴 마커 | 검은 테두리 마커 | 컴파일 불필요, 추적 안정 | 마커가 마커처럼 보여 디자인 손해 |
| C. WebXR | 네이티브 AR | 평면 인식 | iOS Safari 미지원이라 관객 절반 탈락 |

선택: **A**, B를 폴백으로 남긴다(컴파일이 두 시간 안에 안 풀리면 B로 전환). 내 결정.

### 4.2 실시간 동기화

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 1. AppSync Events(WebSocket) | 호스트 publish, 폰 subscribe | 서버리스, 1초 내, 캡스톤 서사(AWS) | API 키 공개(config.json) |
| 2. S3 state.json 폴링 | 호스트가 Lambda로 파일 갱신, 폰이 2초 폴링 | 단순 | 지연, CloudFront 캐시와 싸움 |

선택: **1**. 클라이언트는 aws-amplify의 `events` 모듈로 붙이고, 인터페이스 뒤에 두어 로컬 모의 구현과 교체 가능하게 한다. API 키는 publish와 subscribe에 모두 쓰이므로 URL을 아는 누구나 호스트가 될 수 있다. 데모 한정 제약으로 문서에 적고, 다음 단계로 Lambda 권한 부여자(암호)를 남긴다. 내 결정.

### 4.3 데이터 공급

| 안 | 내용 |
|---|---|
| a. 빌드 시 스냅샷 | 이 세션에서 MCP로 25구×3개월을 받아 집계 JSON을 정적 파일로 배포 |
| b. Lambda 라이브 | API 키를 SSM에 두고 Lambda가 매일 집계 |

선택: **a**. 키가 AWS에 들어가지 않고, 데모가 네트워크 상태에 흔들리지 않는다. b는 다음 단계. 내 결정.

### 4.4 지도 기하

자치구 폴리곤 GeoJSON은 외부 다운로드가 필요하고 이 세션의 가드가 막는다. 그래서 기하 공급을 두 가지로 둔다. (1) 타일 지도: 25구를 서울 모양에 가깝게 배치한 사각 타일, 내장, 항상 동작. (2) 실제 폴리곤: 사용자가 `tools/geo/raw/`에 파일을 놓으면 변환해 교체. 둘은 같은 Geo 형식을 낸다. 내 결정.

## 5. 설계

### 5.1 구성

```
seoul-ar/
  docs/CONTRACTS.md          ← 모듈 계약서(스키마·시그니처). 모든 작업자가 읽는 단일 기준
  tools/                     ← Node 24 ESM, vitest. 데이터 집계, 지오 변환, 마커 생성·컴파일
  frontend/                  ← Vite 8 + TypeScript + three + mind-ar + aws-amplify(events)
  infra/                     ← CDK(JS, showcase 스택 패턴 계승) us-east-1
```

### 5.2 화면

- `#/` 랜딩: 제목 "서울이 선다", 버튼 두 개 "카메라로 보기"(AR) "3D로 보기", 작은 "발표자" 링크.
- `#/ar`: 시작 버튼(iOS는 사용자 제스처 필요) → 카메라 → 스캔 안내 "슬라이드의 그림을 비춰 주세요" → 타깃 인식 시 그림 위에 서울 등장 → 바텀시트(구 이름, ㎡당 중앙값, 거래 건수, 최고가, 지표 토글, "라이브 따라가기" 상태). 카메라 거부·미지원이면 `#/3d`로 보내고 토스트.
- `#/3d`: 같은 씬, 손가락 회전·확대, 천천히 자동 회전, 같은 바텀시트.
- `#/host`: 왼쪽에 마커 그림과 QR(현재 주소에서 생성), 오른쪽에 월 토글, 25구 격자 버튼, 지표 토글, "전체 보기", 연결 상태. 바꾸면 즉시 publish. S 키나 버튼으로 "슬라이드 모드"(그림·QR·제목만 전체 화면).

```
┌───────────────────────────── #/ar (폰) ─────────────────────────────┐
│  [카메라 영상]                                                        │
│            ┌─ 그림 위 ─┐                                              │
│            │ ▲▲ 서울 3D │  ← 선택 구 상승, 법정동 막대                │
│            └───────────┘                                              │
│ ┌──────────────────────────────────────────────────────────────────┐ │
│ │ 강남구 · 2026년 11월               라이브 ●                        │ │
│ │ ㎡당 중앙값 2,890만원   거래 34건   최고 52.6억                     │ │
│ │ [가격] [건수]                                3D로 보기 →          │ │
│ └──────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

### 5.3 3D 씬

- 지도는 XZ 평면, y 위. 도시 전체가 [-0.5, 0.5]² 안에 들어간다(MindAR 타깃 폭 1 단위에 맞춤).
- 25구 돌출 두께 0.02. 전체 보기에서는 구 색이 지표 값(구 요약)으로 칠해진다. 선택 구는 y 0.03까지 떠오르고 나머지는 어두워진다.
- 법정동 막대: 선택 구의 경계 상자 안에 값 내림차순 정렬 격자로 배치(InstancedMesh). 높이 0.02~0.35. 가격 지표는 ㎡당 중앙값, 건수 지표는 거래 건수. 상위 5개 법정동과 구 이름에 한글 라벨(캔버스 스프라이트, 카메라를 향함).
- 성장 애니메이션 ease-out 0.6초. reduced-motion이면 즉시.
- 팔레트: 어두운 남색 바탕 위 순차 램프(깊은 파랑에서 따뜻한 호박색). 값 없는 동은 회색.

### 5.4 데이터

- 집계 단위: 구·월·법정동. 유효 거래 = 취소일(RTRCN_DAY) 비어 있음. 취소 건수는 별도 집계.
- ㎡당 가격 = 거래금액(만원) / 건물면적(㎡), 면적 0 초과만. 정수 만원/㎡.
- 법정동 통계: n, cancelled, nApt, medPerM2, medPerM2Apt(아파트 0건이면 null), medAmt, maxAmt, usage(유형별 건수).
- 구 요약은 index.json에 월별로 들어가 전체 보기 색에 쓰인다.
- 출력에는 행 단위 데이터, 본번, 부번, 건물명이 없다. 테스트가 이를 확인한다.
- 한 구·월 1000건 도달 시 `truncated: true`로 표기한다.

### 5.5 실시간

채널 `/seoul/state`, 메시지 `{v:1, type:"state", month, gu|null, metric:"price"|"count", ts}`. 뷰어는 라이브 상태를 따르되 직접 구를 고르면 "따라가기"가 꺼지고 "라이브로 돌아가기" 버튼이 뜬다.

### 5.6 인프라

`SeoulArStack`(us-east-1): 비공개 S3 + CloudFront OAC(기본 문서 index.html, 403/404는 index.html 200) + `appsync.EventApi`(API 키 인증, 90일 만료, 네임스페이스 `seoul`) + BucketDeployment(`frontend/dist` 전체와 배포 시 생성되는 `config.json`, Cache-Control no-cache, prune, `/*` 무효화). 출력: CloudFrontUrl, EventsHttpEndpoint, EventsRealtimeEndpoint. CDK 테스트는 `aws-cdk-lib/assertions`와 `node --test`.

### 5.7 마커

`tools/marker/make-slide.mjs`가 추적용 그림 `frontend/public/marker/target.png`(정사각 1024, 특징점이 풍부한 비반복 구성: 서울 지도 실루엣·다양한 점 질감·제목 타이포)를 만든다. `tools/marker/compile-target.mjs`가 `target.mind`를 만든다(Node에서 MindAR 오프라인 컴파일러 + tfjs CPU 백엔드, 안 되면 헤드리스 크로미움). 호스트 페이지가 이 그림을 크게 보여 주므로 별도 슬라이드 파일은 선택이다. QR은 호스트 페이지가 현재 주소로 그린다.

## 6. 빌더에게 맡기는 것

- 타일 지도의 정확한 배치 좌표, 라벨 글자 크기, 바텀시트의 세부 간격.
- 마커 그림의 구체적 구성(단, 특징점 풍부·비반복·고대비).
- MindAR 컴파일 경로(Node 또는 헤드리스). 둘 다 안 되면 AR.js 패턴 마커로 전환하고 보고.
- Amplify events 설정의 세부(엔드포인트 형식은 계약서 참고).

## 7. 데모 운영 메모

- 발표 전: 호스트 페이지를 발표 화면에 띄우고 슬라이드 모드. 관객에게 QR.
- 리허설 항목: 조명에서 인식 거리(0.5~2m), iOS 카메라 권한 안내, Wi-Fi 없을 때 LTE로 동작.
- 끝나면 `npx cdk destroy`로 내린다(API 키와 배포 전부 삭제).

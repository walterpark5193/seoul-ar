# 서울이 선다 (seoul-ar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 폰 카메라로 발표 화면의 그림을 비추면 그림 위에 서울 25개 구와 법정동 실거래 막대가 3D로 서고, 발표자의 선택이 모든 폰에 실시간 반영되는 웹앱을 CDK로 us-east-1에 배포한다.

**Architecture:** 정적 프론트(Vite+TS+three+mind-ar)를 S3(비공개)+CloudFront(OAC)로 배포하고, 발표자 상태는 AppSync Events 채널 하나로 publish/subscribe 한다. 데이터는 이 세션의 MCP `search_trades`로 받은 3개월 스냅샷을 빌드 시 집계해 정적 JSON으로 싣는다. 지도 기하는 타일 폴백과 실제 폴리곤 두 공급원이 같은 `Geo` 형식을 낸다.

**Tech Stack:** Node 24, Vite 8, TypeScript 5, three 0.187, mind-ar 1.2.5, aws-amplify 6 (events), vitest 5, sharp, qrcode, aws-cdk-lib 2.277 (JS, CommonJS), `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-17-seoul-ar-design.md`. 모듈 계약: `docs/CONTRACTS.md` (모든 이름·스키마·시그니처의 기준. 각 Task의 Interfaces는 계약서 절 번호를 가리킨다).

## Global Constraints

- 명령문(Bash)에 `http://`, `https://`, `wss://`를 쓰지 않는다. 세션 가드가 차단한다. 파일 내용에는 써도 된다.
- 결과물(JSON, 코드, 화면)에 본번 MNO, 부번 SNO, 건물명 BLDG_NM, 행 단위 거래, API 키가 들어가면 실패. 원자료는 `tools/data/raw/`에만 두고 git 제외.
- 금액 만원 정수, 면적 ㎡, ㎡당 가격 만원/㎡ 정수. 구 이름과 순서는 CONTRACTS 1절 `GU_ORDER` 그대로.
- 외부 CDN·외부 폰트·런타임 외부 호출 금지(AWS 엔드포인트 제외). 글꼴 스택: "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif.
- 리전 us-east-1. 스택 이름 `SeoulArStack`.
- 작업자는 커밋하지 않는다(컨트롤러가 함). 다른 Task의 소유 파일을 고치지 않는다. 의존성 추가는 보고서에 적는다.
- 이 머신에는 브라우저가 없다. 브라우저가 필요한 확인은 "미확인"으로 보고서에 적는다. 거짓 확인 금지.
- 접근성: 색만으로 구분하지 않음, `prefers-reduced-motion` 존중, 명도 대비 4.5:1.

## Review Focus

1. 유효 거래가 0건인 구·월(또는 법정동): `n: 0`, 중앙값 `null`, 화면은 "거래 없음"을 보여야 하고 NaN·Infinity·빈 화면이 나오면 안 된다. 테스트: Task 1 `aggregate: empty rows`, Task 3 `heightFor(null)`, Task 4 `sheet renders 거래 없음`.
2. `ARCH_AREA`가 0이거나 누락된 행(단독다가구 등): ㎡당 통계에서 빼되 `n`과 `medAmt`에는 넣어야 한다. 테스트: Task 1 `aggregate: area zero excluded from perM2 only`.
3. 원격 상태 메시지가 손상되거나 다른 버전일 때: 무시하고 현재 상태 유지. 테스트: Task 4 `isStateMessage rejects malformed`, `reduce ignores remote when follow=false`.
4. 카메라 거부·미지원: `#/ar`가 `#/3d`로 보내고 토스트. 테스트: Task 4 `arView falls back when arSupported() false` (arSupported 주입).
5. 법정동이 1개뿐이거나 40개 이상인 구: 격자가 경계 상자 안에 들어가고 막대 한 변이 양수여야 한다. 테스트: Task 3 `layoutBars single`, `layoutBars 45 dongs fit bounds`.
